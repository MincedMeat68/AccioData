# Background Screening Package Builder - Technical Assessment

## Quick Start

Welcome! This folder contains everything you need for your technical assessment.

### Contents

```
.
├── ASSESSMENT.md          # Full assessment specification (start here!)
├── ASSESSMENT.pdf         # PDF version for offline reading
├── README.md              # This file
└── assets/
    └── mockups/
        ├── embedded/      # UI mockup images extracted from spec
        └── pages/         # Full page renders of the specification
```

### Getting Started

1. **Read the full assessment** in `ASSESSMENT.md` or `ASSESSMENT.pdf`
2. **Review the mockups** in `assets/mockups/embedded/` for UI design guidance
3. **Set up your project** with Next.js (frontend) and Sinatra (backend)
4. **Build the application** following the requirements
5. **Submit** via GitHub repo or zip file

### Time Limit

**4 hours** - Focus on core requirements first, then stretch goals if time permits.
